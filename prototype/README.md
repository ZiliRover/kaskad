# Seedance Studio

Десктоп-приложение (Windows) для генерации видео семейством Seedance через OpenRouter.
Нодовый канвас в стиле Weavy: промты, изображения и модели соединяются в цепочки.

## Запуск

**Установленная версия**: ярлык «Seedance Studio» в меню Пуск (стоит в `%LOCALAPPDATA%\Programs\Seedance Studio`).

**Установка на другой ПК**: скопируй туда `installer\SeedanceStudio-Setup-1.0.0.exe` и запусти — админ-права не нужны, Python тоже не нужен (всё внутри). Нужен только WebView2 (в Windows 10/11 есть по умолчанию). После установки вставь ключ OpenRouter в настройках (шестерёнка) — ключ в установщик намеренно не зашит.

**Dev-режим**: `start.bat` или `python app.py` из этой папки (`pip install -r requirements.txt`).

**Пересборка exe и установщика**: `build.bat` (PyInstaller + Inno Setup, результат в `dist\` и `installer\`).

В установленной версии рабочие файлы (веб-часть, настройки, готовые видео) живут в `%LOCALAPPDATA%\SeedanceStudio`, видео — в подпапке `web\outputs`.

## Модели

- **Видео (Seedance, OpenRouter `/api/v1/videos`)**: Seedance 2.5, 2.0, 2.0 Fast, 2.0 Mini, 1.5 Pro. Список подтягивается с OpenRouter при запуске, так что новые версии семейства появятся сами. Параметры: разрешение (до 4K у 2.0), формат кадра, длительность (до 30 сек у 2.5), аудио, seed, image-to-video (первый/последний кадр).
- **Картинки**: Nano Banana Pro / 2 / 1, GPT-5 Image (Mini).
- **Текст**: ByteDance Seed 2.1 Turbo, 2.0 Code/Lite/Mini, 1.6 (Flash).

## Деньги

В шапке три счётчика: **Баланс** (кредиты OpenRouter), **Сессия** и **Всего** — суммируются из реальной стоимости (`usage.cost`) каждой генерации. У каждой ноды после запуска видна цена конкретного результата.

## Ключ

Ключ OpenRouter берётся из `.env` (`OPENROUTER_API_KEY=...`) или задаётся в настройках (шестерёнка) и хранится локально в `settings.json`.

## Как пользоваться

- Перетащи ноду из левой панели на холст (или кликни по ней).
- Соединяй порты перетаскиванием: цвет порта = тип данных (голубой — текст, жёлтый — картинка, розовый — видео).
- «Запустить» на ноде — выполняет её (недостающие входные ноды запускаются сами). «Запустить всё» — весь граф по порядку.
- Готовые видео сохраняются в `web/outputs/`, кнопка «Экспорт» — сохранить куда угодно.
- ЛКМ по фону — панорама, колесо — зум, Delete — удалить выбранное. Граф автосохраняется.
