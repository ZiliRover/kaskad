## 1. Суть

Веб-сервис, где на нодовом холсте (как Weavy / Figma Weave, Krea Nodes, Freepik Spaces) собираются цепочки генераций:
текст → картинка → видео → апскейл → монтаж. Лучшие мировые модели в одном месте,
**без VPN, с оплатой в рублях, на русском языке**, с готовыми шаблонами под реальные задачи.

## 2. Почему это купят в РФ

Сам холст — не преимущество: у зарубежных игроков он уже есть и лучше профинансирован.
Преимущество — то, чего им не хватает в РФ:

1. **Доступ**: модели работают без VPN и зарубежной карты.
2. **Рубли**: предоплата кредитов картой РФ / СБП, чеки.
3. **Шаблоны**: пользователь не собирает граф с нуля, он берёт готовый сценарий
   («фото товара → 5 карточек + 10-сек. видео») и при желании допиливает.
4. **Русский язык**: интерфейс, промты на русском с авто-переводом/улучшением под модель.

Российские агрегаторы (Syntx, BotHub, GPTunnel, GenAPI и т.п.) — это чаты и боты «одна модель → один результат».
Цепочек и переиспользуемых сценариев у них нет. Это наша ниша.

## 3. Аудитория

Продукт универсальный, но **выходим на рынок последовательно** — одному человеку не вытянуть маркетинг и шаблоны под всех сразу.

| Очередь | Сегмент | Почему |
|---|---|---|
| 1 | AI-креаторы, клипмейкеры, моушн-дизайнеры | Автор сам в этой аудитории → быстрый фидбэк на себе. Ценят цепочки и контроль. |
| 2 | Селлеры WB/Ozon | Большой рынок, понятные деньги, повторяемые задачи → шаблоны продают сами себя. |
| 3 | SMM и агентства | Серии креативов, ресайзы, UGC-ролики; позже — командные пространства. |

## 4. MVP — что входит

- Регистрация/вход (Telegram Login + email).
- Кредиты в рублях: пополнение, баланс, история списаний, цена **до** запуска ноды.
- Холст: ноды Промт, Изображение (загрузка), Генерация картинки, Генерация видео, LLM (улучшить промт / перевести), Апскейл.
- 8–12 лучших моделей (картинки + видео), реестр моделей в данных, а не в коде.
- Очередь задач: генерация видео идёт в фоне, прогресс в реальном времени, можно закрыть вкладку.
- История генераций и галерея, скачивание файлов.
- 5 шаблонов для сегмента №1.
- Подтверждение перед дорогими запусками («Запустить всё: ~₽340, продолжить?»).

## Не входит в MVP

Командные пространства, публичный маркетплейс шаблонов, API для разработчиков, мобильная версия, собственный видеомонтажёр.

## 5. Деньги

- Только **предоплаченные кредиты**, никакой постоплаты.
- Наценка к себестоимости API ~40–60% **[решить после расчёта]**: покрывает курс, комиссии конвертации, эквайринг, налог, возвраты за сбои.
- Перед запуском **резервируем** оценочную стоимость, после — списываем фактическую, остаток возвращаем.
- Неудачная генерация по вине провайдера → кредиты возвращаются автоматически.
- Приветственный бонус на пару картинок, чтобы попробовать без оплаты **[решить]**.

## 6. Юридическая схема (не юр. консультация — сверить с бухгалтером/юристом)

**Старт — самозанятость (НПД):**
- Оформляется за минуты в приложении «Мой налог».
- Налог 4% с физлиц, 6% с юрлиц; лимит дохода 2,4 млн ₽/год; без сотрудников.
- Эквайринг для самозанятых: ЮKassa, Робокасса, Prodamus — чеки уходят в «Мой налог» автоматически.
- Продаём **доступ к собственному сервису**, а не «перепродажу API» (перепродажа/агентская деятельность самозанятым запрещена).

**Рост — ИП на УСН** при приближении к лимиту или при найме людей.

**Не делаем:** приём денег на личную карту без оформления (блокировки по 115-ФЗ, риск незаконного предпринимательства),
чужие ИП и «дропы» из рилсов.

**Персональные данные (152-ФЗ):** база пользователей хранится на серверах в РФ. Уведомление в Роскомнадзор как оператор ПДн.

**Контент:** правила использования, запрет дипфейков реальных людей без согласия, модерация промтов **[решить глубину]**.

## 7. Оплата внешних API

Самый большой риск бизнеса: провайдеры (OpenRouter, Google, OpenAI, ByteDance) могут ограничить аккаунт.

- OpenRouter принимает криптовалюту — типовой путь оплаты из РФ. Держим на балансе небольшой запас, не всю выручку.
- С первого дня — **слой абстракции провайдеров**: OpenRouter + fal.ai + Replicate + прямые API (Kling, Hailuo, Wan).
  Если один провайдер отвалился, модель переключается на другой без изменения фронта.
- Рассмотреть российские модели как «легальную базу», которая не зависит от внешних рисков **[решить]**.

## 8. Архитектура (предложение)

- **Фронт:** React + TypeScript + React Flow (стандарт для нодовых редакторов). Визуальный стиль переносим из прототипа.
- **Бэкенд:** Next.js (TS) — решено; Postgres; очередь задач на Postgres (без лишнего Redis на старте).
- **Хранилище файлов:** S3-совместимое в РФ (Yandex Object Storage / Selectel).
- **Реестр моделей:** каждая модель = запись со схемой параметров, ценой и провайдерами → UI ноды строится из схемы автоматически.
- **Деньги:** журнал операций (ledger) — баланс считается из проводок, а не хранится одним числом.
- **Хостинг:** приложение и БД в РФ; воркер генераций может жить за рубежом, если провайдеры режут российские IP **[проверить]**.
